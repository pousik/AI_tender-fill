# V5 — исправления профиля, шаблонов и Vision

1. Шаблон специалиста допускается как частичный и больше не отбрасывается из-за
   отсутствия section_number.
2. Для ТРГ-УЭТМ product_type принудительно определяется как ТРГ-УЭТМ.
3. Изготовитель и марка/тип берутся напрямую из выбранного профиля data_tenders.
4. Targeted Vision использует тот же простой prompt:
   «Извлеки все параметры оборудования и их значения со схемы/изображения.»
5. Невалидный/пустой Vision-ответ не ломает pipeline.
6. Обычный DOCX-запуск не делает сетевых Vision-запросов: используются cache-данные.
   Live Vision включается только через DATA_TENDERS_VISION_LIVE=1.
7. DocumentTracker дополнительно отслеживает Word lock-файл ~$*.docx.
