# ФИО специалиста

ФИО хранится в `tenders.specialist_name`. Оно привязано к сохранённому шаблону тендера.

При завершении редактирования документа `DocumentTracker`:
1. записывает `Заполнил специалист: ФИО` в верхний колонтитул DOCX;
2. сохраняет шаблон вместе с ФИО в SQLite;
3. для PDF-компаньона конвертирует изменённый DOCX обратно в PDF.

В GUI ФИО запрашивается перед обработкой документа. Можно также задать `SPECIALIST_NAME` как значение по умолчанию.
