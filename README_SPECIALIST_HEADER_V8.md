# V8 — гарантированное сохранение ФИО специалиста

ФИО берётся из `self.specialist_name`, установленного через QInputDialog.

При создании DOCX/PDF-редактируемой копии заголовок записывается ДО открытия Word.
После закрытия Word `DocumentTracker` повторяет запись и сохраняет `specialist_name`
в Tender. Для PDF после этого DOCX конвертируется обратно в PDF.

Проверяется повторным чтением сохранённого DOCX.
Строка: `Заполнил специалист: ФИО`.
