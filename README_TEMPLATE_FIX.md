# Исправление шаблонной БЗ

Ключевое изменение: значение больше не определяется по «последней/ближайшей» ячейке.

Для каждой строки DOCX сохраняются:

- `table_index` — номер таблицы;
- `row_index` — номер строки;
- `target_cell_index` — физическая колонка ответа после устранения merge-дубликатов;
- `field_key` — канонический ключ поля;
- `section_number` — номер строки ТЗ.

## Порядок автозаполнения

1. ранее подтвержденный шаблон;
2. константы по типу/напряжению;
3. только оставшиеся пустые поля → GigaChat.

Сгенерированный AI документ **не обучает БЗ автоматически**.
Обучение выполняется после сохранения финального документа инженером.

Исходный документ без явной колонки «Предлагаемое участником конкурса»
не считается шаблоном ответа и не попадает в шаблонную БЗ.

## Старые данные

Шаблоны, созданные старой версией, имеют `field_key = NULL` и
`table_index = NULL`, поэтому новый алгоритм их игнорирует.

Если нужно удалить их из БД после резервного копирования:

```powershell
python tools/reset_legacy_templates.py
```
