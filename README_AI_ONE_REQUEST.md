# AI one-request mode

Для одного документа DOCX AI вызывается максимум один раз. При HTTP 429 повторяется только тот же запрос с backoff. Перехода к многочисленным чанкам нет. Сначала отправляется текущий документ + выбранный профиль data_tenders; при переполнении prompt выполняется один минимальный fallback.
