# Редактирование PDF через Microsoft Word

Для PDF реализован вариант без отдельного PDF-редактора:

1. Автозаполнение создаёт `Заполненный_*.pdf`.
2. Программа конвертирует его через Microsoft Word в `Заполненный_*_для_редактирования.docx`.
3. Редактируемый DOCX автоматически открывается в Word.
4. Инженер редактирует таблицу как обычный Word-документ и сохраняет.
5. `DocumentTracker` ждёт сохранения и закрытия Word.
6. Отредактированный DOCX передаётся в существующий `capture_docx_file()` для обучения БЗ.
7. Тот же отредактированный DOCX конвертируется Word обратно в исходный `Заполненный_*.pdf`.

Требования Windows:
- Microsoft Word;
- `pywin32` (`pip install pywin32`).

Важно: Word при открытии PDF конвертирует его в редактируемое представление. Для сложных сканов/чертежей исходная геометрия PDF может немного измениться — после сохранения обратно в PDF используется разметка Word. Для вашего сценария это сознательно выбрано как пользовательский редактор, аналогичный Word-циклу.
