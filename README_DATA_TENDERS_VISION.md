# GigaChat Vision для data_tenders и PDF

Изображения технических документов больше не читаются Tesseract как основной OCR.
Для семантического распознавания используется GigaChat Vision через `ask_vision_json`.

## data_tenders

`services/data_tenders_knowledge.py`:
- извлекает картинки из DOCX;
- передаёт исходные байты изображения в Vision;
- получает JSON с моделями, параметрами, значениями и единицами;
- привязывает результат к реальным моделям `ТРГ-УЭТМ-*`;
- добавляет распознанные характеристики в тот же индекс, что и таблицы;
- кэширует результат по SHA1 изображения.

## PDF

`services/search_pdf_AI.py`:
- для сканированных/графических страниц делает Vision-анализ;
- Vision используется для смысла, таблиц, размеров, масс, марок и требований;
- Tesseract остаётся только резервом и инструментом определения координат ячеек;
- результаты Vision добавляются в полный `document_text`, поэтому их видит второй AI-проход;
- геометрия PDF не зависит от Vision и продолжает определять, куда физически записывать ответ.

## Переменные окружения

`PDF_VISION_OCR=1` — включить Vision для PDF.
`PDF_VISION_MAX_PAGES=12` — максимум страниц PDF для Vision за запуск.
`PDF_VISION_DPI=220` — разрешение изображения страницы.
`DATA_TENDERS_MAX_IMAGE_OCR=0` — 0 означает обрабатывать все изображения.
`TENDER_AI_DATA_TENDERS_MAX_CHARS=180000` — максимальный размер сериализованного контекста data_tenders.

При недоступности Vision остаётся Tesseract fallback, чтобы проект не становился полностью неработоспособным.
