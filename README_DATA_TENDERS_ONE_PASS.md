# Data Tenders One-Pass

`data_tenders` теперь обрабатывается один раз и результат сохраняется в:

- `.data_tenders_index.json` — структурированный индекс 1356 записей;
- `.data_tenders_context_cache.json` — готовый AI-контекст;
- `.image_ocr_cache.json` — кэш Vision/OCR изображений.

Алгоритм:

1. При первом запуске строится индекс DOCX одним проходом.
2. Для поиска используется хеш-индекс `O(1)` по параметр/модель/напряжение.
3. Нечёткий поиск используется только при отсутствии точного ключа.
4. При следующих запусках DOCX из `data_tenders` заново не открываются, пока файлы не изменились.
5. Vision не вызывается при обычной обработке, если его результат уже есть в кэше.

Для принудительной перестройки:

```powershell
python -c "from services.data_tenders_knowledge import DataTendersKnowledge; DataTendersKnowledge().refresh(force=True)"
```

Если изменились файлы `data_tenders`, индекс автоматически станет неактуальным по сигнатуре и будет перестроен один раз.
